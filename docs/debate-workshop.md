# Debate Workshop Feature

The debate workshop is a separate, buildless page at `debate.html`. The admin feature selector is `admin.html`; the member lobby is `index.html`. It shares the club member roster but stores workshop state under `/debate_sessions`, separate from book voting data. The lobby advertises a debate only after the host starts Round 1; the active session ID is published at `/active_debate_session`.

## Entry modes

- Host: `debate.html?mode=host&admin=1` (requires the authorized Google account)
- Projection: generated by the host for the active session
- Participant: scan the session QR code or open the generated join link

The admin route requires the configured Google account UID in the client. Realtime Database Security Rules must also restrict admin writes to that UID; a browser check alone is not a security boundary.

## Module ownership

- `assets/js/debate/config.js` — Firebase configuration and initialization.
- `assets/js/debate/session-service.js` — Realtime Database subscriptions and writes.
- `assets/js/debate/i18n.js` — EN/DE text and workshop rules.
- `assets/js/debate/views.js` — role-specific markup and state rendering.
- `assets/js/debate/app.js` — route selection, application state, and event coordination.
- `assets/css/debate.css` — page-level styles shared by the three modes.

The page uses native ES modules and relative URLs. It requires no package manager, bundler, or build step.

## Session flow

The host enters one statement per round and creates a session. Members choose their roster name in the lobby; that identity carries into the event, and the debate page joins the selected member automatically. Round 1 choices can be changed; Round 2 choices are written once. The host dashboard shows Round 1 above Round 2, each with per-speaker start, pause, resume, and finish controls. Round 2 stays unavailable until every joined participant has completed their Round 1 turn; the Round 1 card is dimmed after advancing. The projection view shows only aggregate side counts, the current statement, speaker, timer, and reflection questions. Round 2 rule 3 remains unspecified until the club supplies it.
