## Book Club App

- [`index.html`](index.html) — member selects a roster name to enter the lobby, view current events, and see the waiting-room count and date. That member identity carries into the selected event.
- [`admin.html`](admin.html) — admin feature selector for Voting and Debate.
- [`voting.html`](voting.html) — voting member page; admin access requires the authorized Google account.
- [`debate.html`](debate.html) — debate member, projection, and host modes.

See the [Debate Workshop guide](docs/debate-workshop.md) for its screen modes, event lifecycle, and module responsibilities.
